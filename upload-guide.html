📂 File Naming Convention

Every file you submit must follow this exact format so faculty can identify it instantly:

[UserID]_[ProjectCode]_[DocumentType].[extension]
Examples:
mba26-ai-03_P1_CompanyProfile.pdf
mba26-ai-07_P1_ExcelWorkbook.xlsx
mba26-ai-01_P2_JourneyMap.pdf
mba26-ai-05_P4_PowerBIDashboard.pbix
mba26-ai-09_P3_AIReflectionNote.pdf
❌ Do NOT use spaces in file names. Use underscore (_) between parts.
❌ Do NOT rename files after uploading. Faculty uses file names for tracking.
✅ Always export Word documents as PDF before uploading.

📝 GSDC Scenario Answer Submissions

Every Saturday mock test has 1 scenario question that requires a written answer. MCQs are auto-scored on the LMS. Your scenario answer must be submitted separately via Google Form.

1

Attempt the scenario question on mock.html

Read the scenario carefully. Type your answer in the text box provided on the mock page. Take a screenshot or copy your answer before submitting.

2

Submit via the weekly GSDC Scenario Form

A Google Form link is shared every Friday by faculty (via WhatsApp / LMS). It will ask for:

  • Your User ID
  • Module number (M1–M8)
  • Your MCQ score (from the auto-score result)
  • Your scenario answer (paste in text box)
3

Feedback returned before next Saturday

Faculty reviews scenario answers and shares feedback during the Friday doubt session. Your scenario score (out of 30) is added to your mock MCQ score (out of 100).

📌 Scenario submissions submitted after Sunday midnight will not be evaluated for that week's mock. They can still be submitted late but will be marked as "Practice Only."

☁️ Google Drive Setup Guide

All file uploads are done by sharing a Google Drive folder link in the Google Form. Follow these steps once:

1

Create your semester folder

In Google Drive, create a top-level folder named: [Your UserID]_MBA26_AI_Submissions
Example: mba26-ai-04_MBA26_AI_Submissions

2

Create one sub-folder per project

Inside, create 4 sub-folders:

P1_MarketEntry   P2_JourneyMap   P3_StartupBMC   P4_Dashboard
3

Set sharing permissions on the main folder

Right-click the main folder → Share → General access → "Anyone with the link" → "Viewer". Copy the link — paste this ONE link into every Google Form submission.

4

Upload files to the correct sub-folder

Before each deadline, upload all project files to the relevant sub-folder using the naming convention above. Faculty will access via the single shared link.

💡 Tip: Use Google Docs/Sheets directly inside Drive to avoid the "convert to PDF" step. For Power BI (.pbix) files, upload to Drive and paste the download link in the form.
